## 1.0.1

Русский: защита не переключает сервер из-за случайных сбоев сети и возвращается к выбранному серверу только после стабильной работы; при уходе на обычный DNS сама ищет другой сервер для ИИ; окно и фоновая защита не мешают друг другу; свои правки списка не теряются; исправления безопасности и причин в журнале.

English: protection no longer switches servers over random network failures and returns to the selected server only after it has worked stably; after falling back to regular DNS it looks for another AI server by itself; the window and background protection no longer interfere; your list edits are kept; security fixes and clearer log reasons.

English: release numbering starts over. Simple and advanced modes, browsers with their own DNS, tray icon, signed updates, install wizard.
