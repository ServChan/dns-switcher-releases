# Переключатель DNS

Программа для Windows 10/11: список DNS-серверов, применение и сброс в один щелчок,
отдельная группа серверов для обхода региональных ограничений ИИ и защита от сбоев.

## Возможности

- Стартовый список: GeoHide DNS, Comss DNS, Xbox-DNS, dns-ai, MagicDNS (для ИИ),
  AdGuard DNS, Google Public DNS, Cloudflare (обычные). Список можно править.
- Шифрование DoH (Windows 11): шаблон регистрируется в `netsh dns encryption`,
  для адаптера включается режим «только зашифрованные», как в «Параметрах».
- Проверка доступности каждого адреса тем способом, каким его использует Windows:
  обычный DNS-запрос по UDP или DoH по HTTPS (HTTP/2 или HTTP/1.1).
- Защита от сбоев: если текущий сервер не отвечает две проверки подряд, а интернет есть,
  подключение переводится на следующий рабочий сервер группы (порядок как в списке),
  затем на обычные DNS и в крайнем случае на DNS от роутера. Когда выбранный сервер
  оживает, программа возвращается к нему. Журнал: `%APPDATA%\DnsSwitcher\events.log`.
- Страховка: Cloudflare 1.1.1.1 и Google 8.8.8.8 дописываются последними адресами,
  чтобы Windows сама ушла на них, даже если программа закрыта.
- Фоновая защита: задание «DnsSwitcher Watchdog» в Планировщике запускает
  `dns-switcher.exe --watch` при входе в Windows.

## Установка

`DnsSwitcher-Setup.exe` при запуске не из `C:\Program Files\DnsSwitcher` показывает
установщик. Он копирует программу туда, создаёт ярлыки и запись в «Приложениях».
Удаление: «Параметры → Приложения» или `dns-switcher.exe --uninstall`.

Программа всегда запускается от имени администратора: это прописано в манифесте exe,
Windows сама показывает запрос UAC.

## Сборка

```
cargo build --release
```

Результат: `target\release\dns-switcher.exe` (он же установщик).
Значок перерисовывается скриптом `python tools/make_icon.py`.

Отладка интерфейса без запроса прав: `DNS_SWITCHER_AS_INVOKER=1 cargo build`.
В отладочной сборке `DNS_SWITCHER_DEBUG_INSTALLER=1` открывает установщик,
`DNS_SWITCHER_DEBUG_THEME=light` включает светлую тему,
`DNS_SWITCHER_DEBUG_DIALOG=failover|log|editor|confirm` открывает диалог.

Проверка серверов на живой сети:
`DNS_SWITCHER_AS_INVOKER=1 cargo test -- --ignored --nocapture`.
