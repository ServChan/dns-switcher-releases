# Переключатель DNS

Программа для Windows 10/11: список DNS-серверов, применение и сброс в один щелчок,
отдельная группа серверов для обхода региональных ограничений ИИ и защита от сбоев.

## Возможности

- Стартовый список: GeoHide EU, MagicDNS, dns-ai, GeoHide US, Comss DNS, Xbox-DNS
  (для ИИ, порядок по замерам задаёт очередь резерва), AdGuard DNS, Google Public DNS,
  Cloudflare (обычные). Список можно править; сохранённый нетронутый список
  обновляется до нового стартового автоматически.
- Шифрование DoH (Windows 11): шаблон регистрируется в `netsh dns encryption`,
  для адаптера включается режим «только зашифрованные», как в «Параметрах».
- Проверка доступности каждого адреса тем способом, каким его использует Windows:
  обычный DNS-запрос по UDP или DoH по HTTPS (HTTP/2 или HTTP/1.1). Для серверов
  обхода ограничений ИИ проверка идёт до сервиса: адреса прокси, выданные для
  `chatgpt.com` и `gemini.google.com`, проверяются TLS-соединением с нужным SNI.
  Итог по уровням: работает, часть прокси не отвечает, медленно (дольше 1,5 с),
  сервис не открывается, не отвечает.
- Защита от сбоев: если текущий сервер две проверки подряд медленный, не открывает
  сервис или не отвечает (а интернет есть), подключение переводится на лучший по
  проверке сервер группы (при равенстве выше в списке), затем на обычные DNS и в
  крайнем случае на DNS от роутера. Когда выбранный сервер
  оживает, программа возвращается к нему. Журнал: `%APPDATA%\DnsSwitcher\events.log`.
- Страховка: Cloudflare 1.1.1.1 и Google 8.8.8.8 дописываются последними адресами,
  чтобы Windows сама ушла на них, даже если программа закрыта.
- Фоновая защита: задание «DnsSwitcher Watchdog» в Планировщике запускает
  `dns-switcher.exe --watch` при входе в Windows.

## Установка

`DnsSwitcher-Setup.exe` при запуске не из папки установки открывает мастер:
начало, параметры (папка, ярлыки, запуск без UAC, фоновая защита), ход установки
по шагам с кнопкой «Повторить» и итог с тем, что было настроено. Если программа
уже стоит, мастер предлагает обновить её или удалить. Удаление из «Параметры →
Приложения» запускает тот же мастер (`dns-switcher.exe --uninstall`): можно сразу
вернуть DNS на автоматический и удалить настройки.

Программе нужны права администратора, она запрашивает их сама при запуске.
С настройкой «Открывать без запроса прав администратора» установщик создаёт
задание «DnsSwitcher Launcher», и ярлык открывает программу сразу, без окна UAC.
Окно программы открывается в одном экземпляре: повторный запуск выводит его вперёд.

## Сборка

```
cargo build --release
```

Результат: `target\release\dns-switcher.exe` (он же установщик).
Значок перерисовывается скриптом `python tools/make_icon.py`.

Отладочная сборка не запрашивает права администратора.
В ней `DNS_SWITCHER_DEBUG_INSTALLER=1` открывает мастер установки
(`DNS_SWITCHER_DEBUG_PAGE=options|progress|failed|finish|update|uninstall` выбирает страницу),
`DNS_SWITCHER_DEBUG_THEME=light` включает светлую тему,
`DNS_SWITCHER_DEBUG_DIALOG=failover|log|editor|confirm` открывает диалог.

Проверка серверов на живой сети:
`cargo test -- --ignored --nocapture`.
