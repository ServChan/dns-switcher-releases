# Переключатель DNS: руководство

[English version](USER_GUIDE_EN.md)

## Установка

`DnsSwitcher-Setup.exe` при запуске не из папки установки открывает мастер: начало, параметры (папка, ярлыки, запуск без UAC, фоновая защита), ход установки с кнопкой «Повторить» и итог. Если программа уже стоит, мастер предлагает обновить её или удалить.

Программе нужны права администратора, она запрашивает их сама. С настройкой «Открывать без запроса прав администратора» установщик создаёт задание «DnsSwitcher Launcher», и ярлык открывает программу без окна UAC.

## Простой и подробный режим

Простой режим подходит, если нужно просто чтобы всё работало: карточка показывает состояние цепочки, а «Подобрать лучший сервер» делает выбор за вас. Раздел «Как это работает» объясняет цепочку схемами.

Подробный режим показывает весь список, ручной выбор и проверку каждого адреса и прокси.

## Серверы

Стартовый список: GeoHide EU, MagicDNS, dns-ai, GeoHide US, Comss DNS, Xbox-DNS (для ИИ, порядок задаёт очередь резерва), AdGuard DNS, Google Public DNS, Cloudflare (обычные). Обновление списка меняет только стандартные серверы, которые вы не правили.

## Защита от сбоев

После двух плохих проверок подряд программа переключается на лучший по проверке сервер, при равенстве на более надёжный по истории, затем на стоящий выше в списке. Дальше идут обычные DNS и DNS от роутера. Когда выбранный сервер снова работает, программа возвращается к нему. Cloudflare и Google остаются страховкой последними адресами.

Журнал: `%APPDATA%\DnsSwitcher\events.log`.

## Браузеры

Браузер со своим защищённым DNS обходит настройки Windows. Программа находит такие браузеры и исправляет настройку, закрывая и снова открывая браузер.

## Удаление

Через «Параметры → Приложения» запускается тот же мастер (`dns-switcher.exe --uninstall`). В нём можно сразу вернуть DNS на автоматический и удалить настройки.

## Для разработки

Ключ подписи создаётся один раз: `scripts\release\new-updater-key.ps1` (закрытый ключ в диспетчере учётных данных, открытый в `assets\updater.pub`, встраивается при сборке).

- Выпуск: `scripts\release\publish.ps1 -Notes "..." -Publish`.
- Список серверов: поднять `version` в `release\servers.json`, затем `scripts\release\publish-servers.ps1 -Publish`.

Программа берёт список из `servers.json` и `servers.json.sig` в корне ветки `main`, а новую версию из выпусков этого репозитория.

Отладочная сборка не запрашивает права администратора. `DNS_SWITCHER_DEBUG_INSTALLER=1` открывает мастер установки (`DNS_SWITCHER_DEBUG_PAGE=options|progress|failed|finish|update|uninstall` выбирает страницу), `DNS_SWITCHER_DEBUG_THEME=light` включает светлую тему, `DNS_SWITCHER_DEBUG_DIALOG=failover|log|editor|confirm` открывает диалог.
